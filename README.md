# Ascend

A personal curriculum in 8-week seasons: a job-focused data analytics path, practical photography, reading with habit support, an interests shelf, and field trips around Cape Town.

Live: https://letlhogonolo-kgatshe.github.io/ascend/

- Progress is saved in the browser. Turn on **Sync across devices** (Progress tab) with a GitHub token that only has the `gist` permission; each device then syncs through a secret gist called "Ascend sync data".
- `events.json` is refreshed every Monday with upcoming Cape Town events.
